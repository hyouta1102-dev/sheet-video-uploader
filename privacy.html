Privacy Policy

プライバシーポリシー

Last updated / 最終更新: September 30, 2026

1. YouTube API Services

Sheet Video Uploader uses YouTube API Services. By using this tool, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

本ツールは YouTube API サービスを使用しています。本ツールの利用により、YouTube 利用規約に同意したものとみなされます。Google によるデータの取り扱いは Google プライバシーポリシーをご確認ください。

2. Information we access / アクセスする情報

  • YouTube: the authorized channel's ID and name (to confirm the upload destination), and permission to upload videos and set thumbnails on that channel.
    YouTube：投稿先を確認するためのチャンネル ID と名前。動画とサムネイルをアップロードする権限。
  • Google Sheets: read and write access to the one spreadsheet configured by the user, to read upload requests and write back results.
    Google スプレッドシート：利用者が設定した1つのスプレッドシートの読み書き（投稿内容の読み取りと結果の書き戻し）。
  • Google Drive: read-only access to the video and image files linked in that spreadsheet.
    Google ドライブ：シートにリンクされた動画・画像ファイルの読み取りのみ。

3. How we use and store information / 利用と保存

  • Information is used only to upload the user's videos to the user's own YouTube channel, with the title, description, hashtags, privacy setting and publish time exactly as the user entered them.
    情報は、利用者が入力した内容のとおりに、利用者自身のチャンネルへ動画をアップロードする目的にのみ使用します。
  • The OAuth token is stored only on the user's own computer. It is not sent anywhere other than Google.
    認証トークンは利用者自身のパソコンにのみ保存し、Google 以外には送信しません。
  • Video and image files are downloaded to a temporary folder on the user's computer and deleted immediately after each upload.
    動画・画像ファイルは一時フォルダに保存し、アップロード後すぐに削除します。
  • The only YouTube data written anywhere is the URL of each uploaded video, written to the user's own spreadsheet. The user can edit or delete it at any time.
    保存される YouTube のデータは、利用者自身のスプレッドシートに書き込まれる動画 URL のみで、利用者はいつでも編集・削除できます。
  • We do not operate any server that collects user data, and we do not share, sell or transfer any information to third parties.
    利用者データを収集するサーバーは運用しておらず、第三者への提供・販売・移転は行いません。

4. Cookies and third-party content / Cookie と第三者コンテンツ

This tool and this website do not use cookies, advertising, or analytics, and do not allow third parties to serve content or collect information from users.

本ツールと本サイトは Cookie・広告・アクセス解析を使用せず、第三者によるコンテンツ配信や情報収集も行いません。

5. Revoking access and deleting data / アクセスの取り消しとデータの削除

You can revoke this tool's access at any time in either of these ways:

  • Run python3 uploader.py --revoke. This revokes the authorization with Google and immediately deletes the stored token and temporary files.
    --revoke を実行すると、Google 側の許可を取り消し、保存したトークンと一時ファイルを直ちに削除します。
  • Remove "Sheet Video Uploader" from the Google security settings page.
    Google アカウントのセキュリティ設定ページから削除することもできます。

After revocation, any remaining stored data is deleted within 7 days.

取り消し後、残っている保存データは7日以内に削除します。
